# Dlife · 拾光

一个以个人生活记录为核心的开源网站。默认黑色界面，支持文字、照片、视频、每日心情曲线、可定制小精灵、邀请码注册和可安装的桌面网页应用。AI 聊天目前按站长选择暂未接入。

## 功能

- 私人生活时间线：新建、编辑、搜索、日期筛选，以及删除后撤销。
- 上传 JPG、PNG、GIF、WebP 照片和 MP4、MOV、WebM 视频。每条最多 6 个附件，单文件最大 20 MB。
- 每天主动选择 1–5 分心情；近 7 / 30 天曲线只显示真实评分，缺失日期留空。点击曲线中的日期查看生活记录。
- 定制精灵名字、颜色、外形和陪伴性格；「生成一只」通过程序生成精灵组合，无图片生成费用。
- AI 聊天通过服务端 OpenAI Responses API 提供。只发送聊天内容，不会自动发送日记、照片、视频或心情。最近 12 条聊天作为上下文，每个用户每天最多 50 次成功请求。
- 自定义背景、点缀色、字体和记录留白，设置随账号保存。
- 导出文字、评分、设置、聊天的 JSON 文件；附件需单独保存。

## 朋友内测：用户名、密码与邀请码

- 使用 Better Auth 处理密码和登录会话。注册页面只收集用户名、密码与邀请码，不收集邮箱。
- 密码至少 7 个字符。库需要的内部 email 字段使用随机、不可投递的 `.invalid` 标识；不代表真实联系邮箱，不发送邮件。
- 邀请码由站长生成，每个只可注册一次，7 天有效，可以撤销。注册入口由服务器核验邀请码；通用邮件注册接口不对外提供。
- 注册后显示一次随机恢复码，服务器只保存其摘要。请私下保管；恢复密码后，旧恢复码和用户名登录会话失效，并生成新恢复码。
- 日记、附件和心情按账号隔离。朋友没有查看他人记录或管理邀请的权限。
- 首次创建站长账号时，将原有 ChatGPT 身份对应的记录关联到新账号，不搬动或公开记录。保留站长原有登录方式。

### 部署顺序

1. 保持 Sites 主人私有访问，配置全新的服务端 `DLIFE_AUTH_SECRET`（至少 32 字符）、本站完整域名 `DLIFE_AUTH_URL`，以及 `DLIFE_OWNER_SETUP=enabled`，再发布。
2. 网站主人通过既有 ChatGPT 登录打开 `/account`，点击「建立站长账号」，自行设置用户名和密码，保存恢复码。
3. 确认站长角色已建立后，将 `DLIFE_OWNER_SETUP` 设为 `disabled` 并重新发布。再由站长授权将网站入口设为可公开访问，独立账号与邀请码继续保护所有数据与注册操作。
4. 在「账号与邀请」中生成邀请码，私下把网站链接和邀请码发给朋友。朋友用自己的用户名和密码注册。

**不要在站长初始化完成前公开网站，也不要把站长初始化模式用于已公开的空数据库。** 初始阶段的身份信任来自 Sites 主人私有访问边界；部署到其他环境时，应另行实现受保护的站长初始化。

## 桌面版（PWA）

`/install` 提供 Mac 与 Windows 安装说明。Chrome / Edge 可从安装入口将网站添加为独立桌面窗口，数据仍保存在网站服务端。它是可安装的网页应用，暂不提供原生 `.dmg` / `.exe` 安装包。

当前版本需要联网。Service Worker 只缓存通用离线说明与图标，绝不缓存日记、媒体、账号页面或接口数据。安装流程需在用户自己的浏览器完成，尚未在独立 Windows 设备验证。

## 隐私与存储

源码公开不代表用户数据公开。所有日记、评分、设置、附件和聊天接口均要求登录，并按服务端用户 ID 限定访问。结构化数据保存在 D1，媒体保存在 R2。网页不包含 API 密钥。

托管版本保留 Sites 的站长身份与初始私有访问边界，新增 Better Auth 独立账号。生产环境不能直接信任来自公网的 `oai-authenticated-user-*` 请求头。其他平台部署需要保护初始站长身份，不能照搬本地模拟认证。

本地开发使用 starter 的模拟账号 `Seedy`，仅在 loopback 开发模式可用。开发数据和线上数据互相独立。

## 从零读懂文件

| 文件                       | 用途                        |
| -------------------------- | --------------------------- |
| `app/journal.tsx`          | 网站主要页面和操作逻辑      |
| `app/globals.css`          | 页面外观、主题与手机布局    |
| `app/api/entries/route.ts` | 保存、读取和修改生活记录    |
| `app/api/moods/route.ts`   | 每日心情评分                |
| `app/api/media/route.ts`   | 私人照片和视频              |
| `app/api/chat/route.ts`    | AI 聊天，只在服务端使用密钥 |
| `db/schema.ts`             | 数据库结构                  |
| `drizzle/`                 | 数据库版本变更              |
| `.openai/hosting.json`     | Sites 托管配置              |

HTML 决定结构，CSS 决定外观，TypeScript 决定交互；本项目用 React 将这些组合成可复用页面。

## 本地运行

需要 Node.js 22.13 或更新版本。

```sh
npm ci
node scripts/init-local-auth.mjs
npm run build
```

首次运行或增加数据库迁移后，将未执行过的 SQL 文件按顺序应用到本地数据库：

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_gorgeous_karen_page.sql
```

同样按顺序应用 `drizzle/0001_rich_mentor.sql`。已经执行的迁移不要重复执行。

独立账号配置由上述脚本保存在忽略的 `.dev.vars` 中。运行：

```sh
npm run dev -- --hostname 127.0.0.1
```

AI 聊天暂未启用，记录、心情、定制和独立账号功能不依赖 OpenAI 密钥。以后如需接入 AI，应通过单独的安全密钥配置流程完成。

打开终端打印的本地地址，进入 `/account`，通过「站长原有 ChatGPT 登录入口」使用本地模拟账号，再建立本地站长用户名。请勿提交 `.env.local`、任何密钥或本地数据库，仓库已配置忽略规则。

## 托管与费用

网站包含服务端身份、数据库、文件存储和 AI 聊天，不能直接以 GitHub Pages 静态网站承载全部功能。GitHub 用于源码开源；当前在线版本使用 Sites 的 Worker、D1、R2 和认证。

自行创建新的 Sites 项目时，应替换 `.openai/hosting.json` 中的项目标识，并配置自己的数据库、文件存储与服务端密钥。不要复用原项目的身份信息。生产环境的 `OPENAI_API_KEY` 必须作为服务端 secret 配置，不能写进源码或浏览器环境变量。

AI API、存储与托管的可用性、额度及费用取决于各自服务。当前每日 50 次限制用于约束聊天调用，不是全站费用上限。心情评分只是个人回顾工具。

## 当前边界

这是首个可运行版本，暂不包含站内相互关注、公开日记、共享相册、推送通知、精灵图片生成和视频转码。没有回收站列表，删除操作可在当前会话中撤销。聊天历史只加载最近 60 条。附件未提供一键打包导出。
